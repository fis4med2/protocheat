# Security

Do not open a public issue for exploits or bypass techniques. Contact the maintainers privately first.

This project ships diagnostics only. The shim crate only logs that it loaded. It must never alter game or anti-cheat behavior.

Prohibited contributions:

- patching EAC or BattlEye binaries
- spoofing attestation, Secure Boot or TPM
- reading or writing other process memory to evade detection
- distributing `.sys` dumps, keys or loaders

Violations lead to closed PRs and blocked accounts.
